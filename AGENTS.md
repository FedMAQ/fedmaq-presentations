# FedMAQ Presentations

- Preserve unrelated work: inspect status and stage only task-owned paths.
- Read `CONTEXT.md` before naming shared terms.
- Read `.agents/rules/beamer-rules.md` before designing or restyling a deck.
- Read `.agents/rules/latex-rules.md` before editing TeX or compiling.
- Read `.agents/rules/tikz-rules.md` before building a diagram or figure.
- Current slide sources and delivered updates—not memory—are state.
- GitHub Issues own live state. Read the [tracker](../fedmaq-experiments/docs/agents/issue-tracker.md) before issue work and [triage labels](../fedmaq-experiments/docs/agents/triage-labels.md) only when triaging; create no status files.
- Read `docs/agents/domain.md` for repository boundaries or shared authority.
- Direct-to-`main`, no PRs (fedmaq-experiments ADR-0017); compile before committing.
